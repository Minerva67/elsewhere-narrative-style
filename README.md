# elsewhere-narrative-style：用「别处发生」的风格写创投和科技长文

想把一条融资新闻、一个公司故事或一位创始人，写成读者愿意读完的长文，而不是一篇通稿。这个 skill 整理了 elsewhere（别处发生）的写法：标题怎么起、开头怎么写、细节怎么用、结尾怎么收。

## 适合什么时候用

- 指定用别处发生的风格写一篇文章
- 把一条融资新闻改写成调查长文
- 写一篇创始人或投资人的人物稿
- 盘点一个行业现象或一批公司

## 你会拿到什么

一篇按三种文体之一写成的稿子：

- **调查长文**：开头直接给出结局和矛盾，章节按冲突而不是时间排列，结尾回到开头的矛盾
- **人物稿**：从一个场景或一条社交动态进入，8–10 个可以单独阅读的小节，最私人的部分放在最后
- **盘点稿**：先选一个和内容有关的形式（考卷、展览、观察列表），再把内容放进去

交稿前会按八条标准自检，例如开头三句有没有给出矛盾、每 500 字有没有一个可核实的具体细节、把公司名换成竞品后这一段是否仍然成立。

## 动笔前它会先检查两件事

- **题目有没有反差**：钱、人，以及一个出乎意料的地方。没有的话先帮你找角度；实在找不到，会直接告诉你这个题目不适合这个风格。
- **素材里的细节够不够**：具体金额、日期、物件、原话。不够时会向你要素材或先去查资料，不会编造细节。

## 怎么用

- 「用别处发生的风格写这家公司被收购的故事」，附上素材
- 「把这条融资新闻改写成 elsewhere 那种长文」

素材越具体，成稿越好。最好包括时间线、关键数字和人物的原话。

## 包含的文件

- `SKILL.md`：选题与素材检查、三种文体、标题写法、句法、细节要求、自检清单
- `references/pattern-library.md`：代表作逐篇拆解、标题示例和改写示范
