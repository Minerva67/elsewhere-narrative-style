# elsewhere-narrative-style

用 elsewhere（别处发生）的叙事风格写中文创投/科技长文——反讽标题+金句副题、结论先行的倒叙悬念、发明"文体外壳"、毫米级细节进论证链、文学引用×行业黑话混排、去神话化的人性视角。凡是用户要求「用 elsewhere 风格 / 别处发生风格 / 像别处那样写」，或要求把融资新闻、公司故事、创始人经历、行业现象写成「特稿 / 深度报道 / 人物稿 / 调查长文 / 有故事感的稿子 / 别太像通稿」时，务必使用本 skill——即使用户没提 elsewhere 三个字。也适用于给现有稿件做「去通稿化」改写、写创投圈活动稿、或为一篇内容起标题和副题。不用于英文稿、学术论文、产品文档或 PRD。

一个 Claude Code skill。来自合集 [claude-skills](https://github.com/Minerva67/claude-skills)。

## 安装

```bash
git clone https://github.com/Minerva67/elsewhere-narrative-style.git ~/.claude/skills/elsewhere-narrative-style
```

装好后在 Claude Code 里输入 `/elsewhere-narrative-style`，或者直接描述任务，符合条件时会自动触发。
